## 终端标识：Bolo Crystal（定稿）

| 项 | 说明 |
|----|------|
| 名称 | **Bolo Crystal / Bolo 水晶** |
| 形象 | 竖向切面水晶与中心核心，顶部使用 `──◆──` 形成独立识别点 |
| 气质 | 精确、透明、可审计；对应 Bolo 的工具执行、权限边界与持久上下文 |
| 终端 | `>=96` 列使用完整源稿，`56–95` 列使用中型水晶，`38–55` 列使用 6 行紧凑水晶 |
| 源稿 | 仓库根目录 `bolo-logo-tui.txt`；生产常量内嵌进单文件 dist，不在运行时读取 cwd |
| 降级 | `BOLO_ASCII=1` 使用 ASCII 水晶；`BOLO_MASCOT=0` 隐藏图形但保留品牌与会话信息 |
| 禁止 | 不使用其它产品的官方 logo、吉祥物轮廓、商标字样或欢迎页版式 |

默认终端形象：

```text
       ◢          ──◆──          ◣

               ╱╲
             ╱╱  ╲
           ╱╱  ╲  ╲
          ╱  ╲  ║  ╲
         ╱    ╲ ║ ╲  ╲
        ╱  ╲  ╔██╗ ╲  ╲
        ╲   ╲ ╚██╝  ╲ ╱
         ╲   ╲ ║  ╱
          ╲   ╲║ ╱        ◥
           ╲   ║╱
            ╲  ║
             ╲_▼
```

`NO_COLOR` 保留 Unicode 形状和布局，只移除 SGR；显式 plain 主题可省略图形。
ASCII 降级只改变字符集，不改变 workspace/model/session 的信息层级。
